# 産総研の地質図

## ツール

`get_geology` で緯度・経度から、地質図の岩相と地質年代を取得できます。

```json
{
  "latitude": 39.700038,
  "longitude": 141.149898
}
```

`get_area_geology` で矩形内に現れる地質の凡例一覧を取得できます。緯度・経度はWGS84で、南から北、西から東の幅はそれぞれ最大0.25度です。

```json
{
  "south": 39.69,
  "west": 141.13,
  "north": 39.71,
  "east": 141.16
}
```

結果は凡例記号順に並びます。`limit` は既定25件、最大100件で、続きがあれば `next_offset` を次の呼び出しの `offset` に指定します。`total` は範囲内の凡例件数です。

産総研地質調査総合センターの20万分の1日本シームレス地質図V2の凡例を返します。地図の縮尺と出典を結果に含めます。地点の地盤強度や敷地の地質調査には、別途適切な資料・調査が必要です。
